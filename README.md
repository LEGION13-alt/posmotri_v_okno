# Видеоплеер «Посмотри в окно»

Веб-приложение для просмотра видео в интерактивных "окнах"

## Контекст проекта

**Учебный проект от [Яндекс Практикум](https://practicum.yandex.ru/)**
- **Макет предоставлен:** Яндекс Практикум
- **Задача:** Доработать стили для приложения с видео в «окнах»

## О проекте

- **Технологии:** HTML5, CSS3 (Flexbox/Grid), БЭМ методология
- **Статус:** Завершен
- **Тип проекта:** Интерактивный видеоплеер
- **Демо:** [Открыть проект](https://legion13-alt.github.io/posmotri_v_okno)

## Техническая реализация

### **Что сделано:**
- **Кастомный скролл** - стилизованные полосы прокрутки
- **Адаптивные карточки** - гибкие элементы интерфейса
- **Интерактивные кнопки и чекбоксы** - кастомные состояния :hover, :active, :focus
- **Семантическая вёрстка** - доступность и SEO-оптимизация
- **Адаптивный дизайн** - корректное отображение на всех устройствах

### **Особенности верстки:**
- Интерактивные элементы управления
- Плавные скролл-эффекты
- Визуальная обратная связь для пользователя
